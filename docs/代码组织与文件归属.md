# 代码组织与文件归属

## 顶层结构

| 路径 | 职责 |
| --- | --- |
| `server/` | 全部运行时代码（服务入口、路由、业务、静态资源） |
| `test/` | 测试用例 |
| `docs/` | 文档 |
| `scripts/` | 开发期工具（生成渲染点基线、扫描文件系统热点） |
| `cache-index/` | 运行时目录索引缓存（可删重建） |
| `cache-gifs/` | 运行时 GIF 与翻转图片缓存（可删重建） |
| `uploads/` | 用户上传内容 |

## server/ 内部

| 子目录 | 职责 | 性质 |
| --- | --- | --- |
| `server/boot.cjs` | 进程入口 | 通用件 |
| `server/lib/cjs-bootstrap.cjs` | 启动引导（载入应用、异常兜底） | 通用件 |
| `server/core/` | HTTP 服务、路由工厂、日志等基础设施 | 通用件 |
| `server/http/` | HTTP 工具（异步文件读取、HTML 工具、路径安全） | 通用件 |
| `server/route/` | 路由注册与鉴权中间层 | 通用件 |
| `server/store/` | JSON 文件读写（原子写、目录存储、备份） | 通用件 |
| `server/config/` | 配置加载与校验 | 通用件 |
| `server/update/` | 自动更新（监控、拉取、重启） | 通用件 |
| `server/auth/` | 登录与密码校验 | 通用件 |
| `server/app.js` | 应用装配：把路由、静态资源、中间层串起来 | 项目业务 |
| `server/routes/` | 各功能端点（浏览、压缩包、上传、收藏、图集、配置、自动更新） | 项目业务 |
| `server/lib/` | 功能实现（目录索引、压缩包解析、GIF 合成、文件名规则、配置读写、工具探测） | 项目业务 |
| `server/public/` | 前端页面、脚本、样式、语言包 | 项目业务 |

"通用件"指与具体业务无关、可整体替换的实现；"项目业务"指本项目的功能实现。

## 前端结构

```
server/public/
  index.html        页面骨架（由若干 HTML 片段组装而成）
  app.js            业务脚本，单文件（由分片按顺序拼接生成）
  api-client.js     统一的接口封装与错误处理
  locales/          中英文案
  fragments/        HTML 片段与样式分片
```

`app.js` 是生成产物，不要直接修改；它的分片源与拼接顺序在 `server/public/fragments/` 与拼接配置中定义，改完需要重新生成。

## 改代码时的约定

| 约定 | 说明 |
| --- | --- |
| 后端语法自检 | 改完 `node --check <文件>` |
| 前端改动 | 必须实际打开页面确认渲染结果，不能只看接口返回 |
| 缓存策略层 | 新增缓存要同时处理「写后失效」与「按指纹失效」两条路径 |
| 数据落点 | 新增运行时数据目录要放在包外，不随包分发 |

## 测试

```bash
cd <项目根> && node --test test/*.test.cjs
```

测试全部使用相对路径与临时目录，不写死本机绝对路径；涉及文件读写的用例在临时目录内自建自清。
