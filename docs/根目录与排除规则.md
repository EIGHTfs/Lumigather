# 根目录与排除规则

## 两种访问模式

| 模式 | 行为 | 何时生效 |
| --- | --- | --- |
| 黑名单模式（默认） | 任意路径都可浏览，只有命中黑名单的路径被拒（返回 403） | 未配置 `fsRoot` 时 |
| 白名单模式（兼容旧部署） | 只能浏览 `fsRoot` 之下的路径 | 显式配置了 `fsRoot` / `fsRoots` 时 |

## 黑名单怎么配

优先级：环境变量 > `config.json` > 内置兜底。

| 位置 | 写法 | 说明 |
| --- | --- | --- |
| 环境变量 | `GALLERY_BLACKLIST_DIRS=/etc:/proc:/sys` | 分隔符 `:` 或 `,` 都支持 |
| 配置文件 | `"blacklistDirs": ["/etc", "/proc"]`（`server/config.json`） | 被环境变量覆盖 |

匹配规则：先把请求路径与黑名单项都解析为真实路径，再按「相等，或位于该项之下」判定。
因此通过符号链接绕到黑名单目录同样会被拦住。

内置兜底清单覆盖常见系统目录（`/proc`、`/sys`、`/dev`、`/etc`、`/usr`、`/var` 等）
与 NAS 上的应用元数据目录。**兜底只是保险，部署时应按自己机器的实际情况显式声明。**

## 排除目录（不显示的系统产物）

部分目录是系统自动生成的，不应出现在浏览列表里：

| 项 | 写在哪 | 默认值 |
| --- | --- | --- |
| `excludeDirs` | `server/config.json` | `["@eaDir"]` |

`@eaDir` 是 NAS 自动生成的缩略图目录；按需追加其他系统目录名即可。

## `directories` 是什么

`server/config.json` 里的 `directories` 不是权限边界，而是：

- 前端目录树与分类的**展示来源**；
- 全量索引的**扫描范围**。

浏览不受它限制（黑名单模式下），但**未列在其中的目录不会被预先索引**，
第一次访问时按需扫描该目录一层，之后命中索引。

## 索引扫描范围

| 场景 | 是否扫描 |
| --- | --- |
| 分类页首次进入 | 只读该分类索引，不扫盘 |
| 进入某个未索引的目录 | 扫该目录一层，写入索引 |
| 目录内容变化（mtime 变新） | 下次访问时只重建这一段 |
| 整树扫描 | 不会发生 |

需要一次性补全索引时用后台重建入口（按目录 / 按分类 / 全量），它不会自动触发。

## 改完什么时候生效

| 改动 | 生效方式 |
| --- | --- |
| 黑名单、排除目录 | 重启服务后生效 |
| 目录内容增删改 | 下次访问该目录时自动反映（依据目录修改时间） |
| 索引损坏或想强制重建 | 删除 `cache-index/` 下对应分类目录，重启后按需重建 |
